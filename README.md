## 🧩 Shared Components

The project now uses reusable shared components for cleaner maintenance.

### Components Folder

```bash
components/
├── header.html
└── footer.html
```

### Header Placeholder

Each page uses:

```html
<div id="header-placeholder"></div>
```

### Footer Placeholder

Each page uses:

```html
<div id="footer-placeholder"></div>
```

### Component Loading

The shared header and footer are loaded through JavaScript from `script.js`.

This makes it easier to update the navigation or footer links once and apply them across the whole website.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/arjumand-codes/arjumandali-xp.git
```

Open the project folder:

```bash
cd arjumandali-xp
```

Run locally using VS Code Live Server.

Important: because the header and footer are loaded using `fetch()`, open the project with **Live Server** instead of double-clicking the HTML file.

---

## 🧪 Local Development

Recommended local setup:

```bash
# Open project in VS Code
code .

# Run with Live Server extension
# Then open:
http://127.0.0.1:5500/
```

Do not open pages using:

```bash
file:///C:/...
```

The shared header and footer may not load correctly from local file URLs because browser security can block `fetch()`.
