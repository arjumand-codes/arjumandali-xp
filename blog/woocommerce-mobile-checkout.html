Fixing a broken checkout flow on mobile

The layout looked fine on desktop and fell apart at 390px. Here's the CSS fix and the one theme setting that was quietly causing it — plus how to check your own WooCommerce store for the same issue.

A client reported that customers were abandoning checkout on their phones — no errors, no crashes, just people quietly leaving. Desktop looked perfect. The moment I opened the checkout page at 390px width, the problem was obvious: the order summary table was pushing past the edge of the screen, forcing an ugly horizontal scroll right where people needed to enter their card details.

The symptom

Specifically: the "Your order" table on the WooCommerce checkout page had a fixed minimum width baked into the theme's CSS. On anything narrower than roughly 420px, the table refused to shrink, so it either overflowed the container or squeezed the coupon field and payment fields into an unreadable stack.

If people are dropping off at checkout specifically — not earlier in the funnel — the first place to check is layout, not payment gateway settings.

Finding the actual cause

I opened Chrome DevTools, set the viewport to 390×844 (a common phone size), and inspected the checkout table directly. The theme had set min-width: 480px on .woocommerce-checkout-review-order-table — almost certainly copied from a desktop-first template and never revisited for mobile.

The CSS fix

The fix itself was small. I overrode the fixed minimum width with a responsive rule scoped to the checkout table, and let table cells wrap naturally instead of forcing a fixed layout:

@media (max-width: 480px) {
  .woocommerce-checkout-review-order-table {
    min-width: 0;
    width: 100%;
  }
  .woocommerce-checkout-review-order-table td,
  .woocommerce-checkout-review-order-table th {
    white-space: normal;
    word-break: break-word;
  }
}

That alone removed the horizontal scroll and let the product names, quantities, and totals stack cleanly on small screens.

The theme setting

There was a second, quieter issue: the theme had a "sticky order summary" option enabled, which pinned the order summary to the top of the viewport on mobile. Combined with the overflow issue, it was covering the coupon field entirely on some devices. Turning that option off for mobile breakpoints (while keeping it on desktop, where there's more room) solved the rest of it.

Checking your own store

If you run a WooCommerce store, it's worth checking your own checkout page the same way:

  • Open your checkout page on an actual phone, or use DevTools' device toolbar set to a common width like 375px or 390px.
  • Try to complete a test order — pay attention to whether any field is cut off, overlapping, or requires horizontal scrolling.
  • Check your analytics for a drop-off specifically on the checkout step versus the cart step — that's a strong signal it's a checkout-specific layout issue, not a general traffic problem.

Frequently asked questions
